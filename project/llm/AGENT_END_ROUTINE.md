# AGENT END ROUTINE — Checklist для завершения сессии

Выполни этот чеклист в конце каждой рабочей сессии перед тем как завершить диалог.

---

## 1. Обновить state/current.md

- [ ] Обновить статус каждого компонента (не начато / в процессе / готово / сломано)
- [ ] Убрать устаревшие записи
- [ ] Добавить что изменилось за эту сессию

## 2. Обновить state/plan.md

- [ ] Отметить завершённые шаги
- [ ] Обновить статус текущего шага
- [ ] Добавить подшаги если они появились в процессе

## 3. Обновить state/issues.md

- [ ] Добавить новые баги/блокеры которые нашли
- [ ] Закрыть / пометить решёнными те что пофиксили
- [ ] Добавить workaround если не фиксили до конца

## 4. Написать session_handoff.md

Заполни шаблон:

```
## Сессия [дата]

### Что сделано
- ...

### Где остановились
Файл: `path/to/file.py`, функция/строка: ...

### Следующий шаг
[Конкретное действие — одно предложение]

### Контекст который важно помнить
- ...
```

## 5. Обновить changelog_recent.md

- [ ] Добавить запись с датой и списком изменений (3–7 строк)
- [ ] Если `changelog_recent.md` превысил ~100 строк — переместить старые записи в `changelog_archive.md`

## 6. Обновить decisions.md (если принимали архитектурные решения)

- [ ] Добавить решение в формате: что → почему → альтернативы которые отклонили

## 7. Финальная проверка

- [ ] Код запускается без ошибок (хотя бы до точки где остановились)
- [ ] Нет незакоммиченных изменений которые нужно сохранить (если используем git)
- [ ] `session_handoff.md` написан так, что другой агент (или ты через неделю) поймёт с чего начать
