# AGENT START — Read This First

## О проекте

**Тема:** Imitation Learning (Behavior Cloning) для управления роботом с дифференциальным приводом.

**Цель:** Обучить нейросеть (MLP) имитировать эксперт-контроллер. Эксперт управляет роботом
из точки A в точку B. Нейросеть смотрит на те же наблюдения и воспроизводит действия эксперта.

**Стек:** Python, PyTorch, NumPy, Matplotlib. Возможно gymnasium для gym-совместимого интерфейса.

**Ключевые компоненты:**
- 2D симулятор дифф-привода (кинематика, дискретный шаг)
- Двухфазный эксперт-контроллер (поворот → движение вперёд)
- Генератор датасета траекторий (obs, action) пар
- BC-модель: MLP, вход 2 → скрытые слои → выход 2
- Обучение: supervised learning, MSE loss
- Оценка: визуализация траекторий, сравнение с экспертом

## Антипаттерны — НЕ делать без явного запроса

| Антипаттерн | Почему плохо |
|---|---|
| Усложнять архитектуру (LSTM, Transformer, VAE) | Базовый BC с MLP — цель. Усложнение создаёт долг |
| Добавлять DL-фичи (dropout, lr scheduler, data augmentation) | Пользователь новичок, перегрузит |
| Трогать симулятор если просят фикс в модели | Разные компоненты, риск регрессий |
| Рефакторить рабочий код без запроса | Нет времени, нет ценности |
| Добавлять gymnasium зависимость без обсуждения | Может не быть в окружении |
| Писать длинные объяснения без запроса | Пользователь знает управление, не нужно объяснять базу |
